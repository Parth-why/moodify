## About

MOODIFY is an early-stage project exploring how music discovery can better reflect how people feel and what they want to listen to.

The product direction combines music intelligence with a user-guided experience. The intention is to make mood-aware music discovery useful without making the experience feel like a questionnaire.

## Product principles

- **Mood-aware discovery:** help listeners find music that fits the moment.
- **Balanced interaction:** combine intelligent recommendations with user control.
- **Respectful personalisation:** mood signals should be treated as uncertain context, not definitive judgments about a person.
- **Clear user agency:** listeners should be able to adjust or dismiss recommendations.

## Current repository status

This repository is currently a starter repository containing this project brief. The application source code, integrations, recommendation logic, and user interface have not yet been added here.

This README describes the product direction, not a list of implemented features.

## Possible development areas

These are areas to explore as the project is designed:

1. Music service integration and track metadata.
2. Mood and preference input that remains optional and user-controlled.
3. Recommendation logic combining listener preferences with contextual signals.
4. A polished interface for playlists, discovery, and saved music.
5. Privacy-first evaluation of any future camera-based mood inference. Camera input should never be assumed or enabled without explicit consent, and inferred emotion should not be presented as a reliable fact.

## Contributing to the project

The first implementation milestone is to define the supported music provider, data model, recommendation approach, and minimum viable user experience before adding integrations.
